# RFC Бот для базы знаний в Cloudflare Workers


### Изменённая архитектура (упрощённая)

- Бот загружает **все** (или самые важные) Markdown-файлы из `src/content/docs/` при старте Worker’а.
- Вся база знаний превращается в один большой **Knowledge Base String** (или несколько секций).
- Этот KB вставляется в **System Prompt** LLM.
- LLM работает как «эксперт, который отлично знает всю эту вики».

### Плюсы такого подхода
- Полная простота (нет Vectorize, embeddings, внешних сервисов).
- Бот всегда отвечает в рамках философии и техник из pl-chat.
- Легко обновлять знания — просто redeploy Worker.

**Минусы**: Контекст LLM ограничен (особенно на Groq/OpenAI). Нужно аккуратно управлять размером KB.

### Ключевой файл: `src/knowledge.ts`

```ts
// src/knowledge.ts
import { marked } from 'marked'; // или просто текст

// Можно вшить содержимое на этапе build, либо скачать при dev
const wikiModules = {
  // Основные разделы
  nvc: await importRaw('../knowledge/nvc.md'),
  jung: await importRaw('../knowledge/jung.md'),
  frankl: await importRaw('../knowledge/frankl.md'),
  techniques: await importRaw('../knowledge/techniques.md'),
  integral: await importRaw('../knowledge/integral.md'),
  // ... другие важные страницы
};

export const KNOWLEDGE_BASE = `
# База знаний Психологического LLM Wiki (pl-chat)

${Object.entries(wikiModules).map(([key, content]) => 
  `## Раздел: ${key.toUpperCase()}\n${content}\n\n`
).join('')}
---

Инструкция: Отвечай строго в рамках этой базы знаний. Цитируй концепции, техники и авторов (Розенберг, Юнг, Франкл и т.д.).
`;

async function importRaw(path: string) {
  // В production — можно использовать import текстом или fetch из raw.githubusercontent.com
  const response = await fetch(`https://raw.githubusercontent.com/anatolii-iumashev/pl-chat/main/src/content/docs/${path}`);
  return await response.text();
}
```

**Альтернатива для Cloudflare** — во время `wrangler deploy` собирать все md-файлы в один JSON/TS-файл через Bun.

### System Prompt (`prompts.ts`)

```ts
export const SYSTEM_PROMPT = `
Ты — эмпатичный интегративный психотерапевт, глубоко знающий базу знаний pl-chat.

${KNOWLEDGE_BASE}

Правила общения:
- Проявляй безусловное принятие и эмпатию.
- Используй техники ННО (наблюдение — чувства — потребности — просьба).
- При запросах про Тень — мягко направляй на интеграцию.
- Давай практические упражнения из раздела techniques.
- Никогда не ставь медицинских диагнозов.
- В конце каждого 3–4 ответа добавляй: «Я ИИ-помощник и не заменяю профессионального психолога или психотерапевта.»
`;
```

### Как обновлять базу знаний

1. Клонируешь `pl-chat` локально.
2. Запускаешь скрипт, который собирает все md из `src/content/docs/` в один файл.
3. Копируешь результат в `src/knowledge/`.
4. `bun run deploy`.

Или делаешь автоматический GitHub Action + wrangler deploy при изменениях в pl-chat.
