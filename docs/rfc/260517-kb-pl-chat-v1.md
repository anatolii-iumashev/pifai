## 1. Введение

Этот документ описывает спецификацию **первой версии базы знаний** для чат-бота психологической поддержки. База знаний строится на технологиях LLM Wiki (Astro + Starlight) и служит фундаментом для обучения и работы чат-бота.

**Цель документа:**
- Определить методологическую базу (авторы, подходы)
- Описать структуру базы знаний
- Зафиксировать источники для ingest в в1
- Задать конвенции для работы с контентом

**Что входит в v1:**
- Базовая структура wiki (`src/content/docs/`)
- Скиллы для работы с вики (`.agents/skills/`)
- Конфигурация Astro/Starlight
- Деплой на GitHub Pages
- Интегральная методология (5 авторов + MBTI)

**Что НЕ входит в v1:**
- Сам чат-бот (NLP-движок, интеграция с мессенджерами)
- Платные API и сервисы
- Сложные тесты личности (только базовые скрининги)

## 2. Методологическая основа

База знаний строится на синтезе **пяти ключевых авторов** плюс **прикладная типология MBTI** как развитие идей Юнга.

### 2.1. Пять основных авторов

|---|-------|---------|----------------|-------------------------|
| 1 | **Маршалл Розенберг** | Ненасильственное общение (ННО) | 4 компонента: Наблюдение, Чувство, Потребность, Просьба | **В каждом ответе** как базовая структура диалога |
| 2 | **Карл Юнг** | Аналитическая психология | Архетипы, Тень, Анима/Анимус, Индивидуация, Коллективное бессознательное | Повторяющиеся паттерны, сильные реакции, сны, самопознание |
| 3 | **Виктор Франкл** | Логотерапия | Воля к смыслу, 3 пути к смыслу, экзистенциальный вакуум, парадоксальная интенция | Потеря смысла, кризисы, фобии, панические атаки |
| 4 | **Кен Уилбер** | Интегральная теория | AQAL (4 квадранта), уровни сознания, линии развития | Мета-карта для навигации по всем подходам, адаптация языка под уровень |
| 5 | **Арнольд Минделл** | Процессуальная психология | Dreambody (тело как сновидение), следование за процессом, усиление симптома | Психосоматика, телесные симптомы, сны с ощущениями |

## 5. Конвенции и правила

### 5.1. Язык и стиль

- **Все wiki-страницы на русском (ru-RU)**
- Тон: эмпатичный, точный, без воды
- Каждая страница заканчивается секцией **«Материалы и источники»**

### 5.2. Frontmatter

Каждая страница (кроме `index.md` и `log.md`) должна иметь:

```yaml
---
title: "Заголовок страницы"
description: "Однострочное описание"
---
```

**Не дублировать `# H1`** — Starlight рендерит `title` как H1 автоматически.

### 5.3. Ссылки

- **Всегда с `.md`** в исходниках: `[текст](./page.md)`
- Плагин `remarkStripMdLinks` уберёт расширения при сборке
- Для index-файлов: `./category/index.md`

### 5.4. Raw-источники

- **Immutable** (только чтение)
- Организация: `raw/YYYY/MMDD/filename.md`
- При ingest с URL: сначала сохранить в `raw/`, потом обрабатывать

### 5.5. Fetch Rule

**Для извлечения контента с URL всегда использовать:**

```bash
summarize "URL" --extract --format md
```

**Не использовать** `web_fetch` или `browser` для первичного извлечения.
