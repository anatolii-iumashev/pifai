# Spec: Цитаты как YAML content collection

## Что сделано

Цитаты хранятся в `src/content/quotes/<author>.yaml`: 21 файл содержит 78 записей. У каждой записи есть текст и одна или несколько тем; контекст, вопрос для размышления и источник указываются при наличии. Astro collection `quoteAuthors` проверяет форму данных и список тем. Тематические страницы в `src/content/docs/quotes/` переведены в MDX и получают цитаты из `<QuoteList />`. Существующие URL раздела сохранены.

## Ключевые решения

- Идентификатор цитаты формируется как `<author>/<номер в YAML-массиве>`. Новые цитаты добавляются только в конец массива.
- Корневой `tsconfig.json` исключает `includes/` из Astro-проверки, потому что самостоятельные проекты имеют собственные настройки TypeScript; сайт и content collections проверяются независимо от них.
- Общий список тем находится в `src/lib/quote-topics.ts`; каждой теме соответствует MDX-страница.
- Авторские блоки на страницах убраны в пользу выборки по теме. Вступительные эпиграфы и цитаты в «Для дальнейшего чтения» остаются оформлением тематических страниц и не входят в 78 записей.
- Remark-плагин обрабатывает ссылки на `.md` и `.mdx`, сохраняя корректные пути Starlight.

## Отклонения от RFC

- 107 цитатных блоков из секций авторов дали 78 записей после объединения повторов одного автора между темами. Дубликаты с разной атрибуцией оставлены отдельными записями, чтобы не назначать авторство без источника.
- Эпиграфы и цитаты из «Для дальнейшего чтения» оставлены в страницах и не перенесены в коллекцию.
- Отдельные материалы бота на 2026-09-28 не загружали цитаты из коллекции. Актуальное состояние (2026-10-22): действующий бот читает YAML-цитаты через пакет знаний (`build-wiki-pack.mjs`); MDX-страницы остаются презентацией для сайта.

## Известные ограничения / дальнейшие шаги

- id зависит от позиции записи; удаление или перестановка записей меняет последующие id.
- В источниках встречаются одинаковые тексты под разными именами авторов; нужно сверить первоисточники перед объединением таких записей.

> **Примечание (2026-10-22):** упоминания «старого бота» (`includes/bot`, Cloudflare Worker) устарели и удалены — в проекте один бот-контур: Bunny Magic Container ([webhook](./includes/webhook.md)) + задача Trigger.dev ([consult](./includes/consult.md)). YAML-цитаты читает действующий бот: их собирает в пакет знаний [build-wiki-pack.mjs](../../../includes/consult/scripts/build-wiki-pack.mjs), MDX-страницы бот не загружает — они презентационные, для сайта.
