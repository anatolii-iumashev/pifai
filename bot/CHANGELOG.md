# Changelog

## [1.1.0] — 2026-05-27

### Added
- **RAG-поиск по wiki** (`retriever.ts`): поиск релевантных статей из базы знаний под каждый запрос пользователя
- **Цитирование источников**: бот цитирует статьи с ссылками на сайт базы знаний (https://anatolii-iumashev.github.io/pifai/)
- **Индекс чанков для поиска**: build-knowledge.ts генерирует 256 поисковых чанков с ключевыми словами
- **Обработка приветствий и провокаций**: адекватные ответы на «Привет», «Кто ты?», «Ты дьявол?»
- **Умная обработка ошибки лимита токенов**: при превышении TPM бот предлагает написать /clear

### Changed
- **Архитектура**: полная KNOWLEDGE_BASE убрана из system prompt, теперь знания подгружаются через RAG per-query
- **System prompt** сокращён и реструктурирован (для соблюдения лимитов Groq 6000 TPM)
- **KNOWLEDGE_BASE_URL** стал настраиваемым через переменные окружения
- **topK** уменьшен с 3 до 2 для экономии токенов
- **Контекст и вопрос** объединены в одно user-сообщение

### Fixed
- URL для index.md теперь корректно конвертируется (без `/index/` в пути)
- LLM больше не выдумывает свои ссылки — строгая инструкция копировать URL из контекста
- Ошибка rate_limit_exceeded обрабатывается с понятным сообщением пользователю
