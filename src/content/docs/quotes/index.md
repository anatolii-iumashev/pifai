# Цитаты великих людей

Добро пожаловать в коллекцию мудрости, собранную Львом Толстым и дополненную другими великими мыслителями.

**~115 цитат** от стоиков, восточных мудрецов, европейских философов и религиозных текстов — сгруппированных по темам для удобного поиска.

## 📖 Как пользоваться этой коллекцией

### Для ежедневного чтения:
1. Выберите одну тему, которая отзывается сегодня
2. Прочитайте 2–3 цитаты
3. Запишите свои размышления в дневник
4. Подумайте, как применить эту мудрость сегодня

### Для работы с конкретной проблемой:
1. Найдите тему, соответствующую вашей ситуации
2. Прочитайте все цитаты в разделе
3. Выберите одну, которая «зацепила» больше всего
4. Размышляйте над ней в течение дня

### Для медитации:
1. Выберите одну цитату
2. Читайте её медленно, вдумчиво
3. Позвольте ей «отозваться» внутри
4. Запишите инсайты
