# Мысли и реальность

> «Наша жизнь — следствие наших мыслей: она рождается в нашем сердце, она исходит из наших мыслей.» — Лев Толстой

Мысли создают реальность. Измени мысли — изменишь жизнь.

## Практика: Работа с мыслями

### Упражнение: Дневник мыслей

**Формат:**

```
Дата: ___________
Время: ___________

📍 Ситуация:
_________________________________

💭 Автоматическая мысль:
_________________________________

😰 Эмоция (0-10):
_________________________________

🔍 Искажение мышления:
□ Катастрофизация
□ Чёрно-белое мышление
□ Чтение мыслей
□ Долженствование
□ Другие: _______

✅ Альтернативная мысль:
_________________________________

😊 Новая эмоция (0-10):
_________________________________
```

---

### Упражнение: Наблюдатель мыслей

**Инструкция:**

1. Сядьте удобно, закройте глаза
2. Наблюдайте за мыслями как облака на небе
3. Не цепляйтесь, не отталкивайте — просто наблюдайте
4. 10–15 минут

**После практики запишите:**

```
👀 Что я заметил(а):
- Какие мысли доминируют?
- Есть ли паттерны?
- Какие эмоции возникают?

💡 Инсайт:
_________________________________
```

---

### Упражнение: Фильтр мыслей

**Каждая мысль проходит через 3 вопроса:**

1. **Это правда?** (или это предположение?)
2. **Это полезно?** (или это разрушает?)
3. **Это добро?** (или это вредит?)

**Если мысль не проходит фильтр — отпустите её.**
