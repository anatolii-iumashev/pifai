## 📋 Product Overview

**ПиФ** — чат-бот психологической поддержки 24/7, основанный на интегральном синтезе 7 психологических подходов + MBTI.

**Миссия:** Сделать психологическую поддержку доступной, безопасной и этичной через AI-агента, который не заменяет терапию, но предоставляет эмпатичную поддержку и техники самопомощи.

---

## 🎯 Problem

### Проблемы пользователей:

1. **Недоступность терапии:**
   - Долгое ожидание записи (недели/месяцы)
   - Высокая стоимость ($50-150/сессия)
   - Стигма обращения к психологу
   - Географические ограничения

2. **Кризисные ситуации:**
   - Панические атаки ночью
   - Суицидальные мысли
   - Острое горе/утрата
   - Нет поддержки 24/7

3. **Незнание с чего начать:**
   - Не понимают, что с ними
   - Боятся осуждения
   - Не знают, как подобрать специалиста

4. **Потеря смысла:**
   - Экзистенциальные кризисы
   - Выгорание
   - Одиночество

## 👥 Target User

### Primary ICP (Ideal Customer Profile):

**Демография:**
- Возраст: 25-45 лет
- Гео: Россия, СНГ, русскоязычные за рубежом
- Доход: средний и выше
- Технологичность: пользуются Telegram, WhatsApp

- Интересуются саморазвитием

**Сценарии использования:**

2. **Поиск смысла:** «Зачем всё это? Потерял цель»
3. **Самопознание:** «Хочу понять себя лучше»
4. **Навыки:** «Научиться справляться с тревогой»

### Secondary Users:

- **HR/Wellness программы** — корпоративное использование
- **Терапевты** — как дополнение к терапии (homework между сессиями)
- **Студенты психологии** — для обучения и практики

## 🎯 Core Use Cases

### UC1: Кризисная поддержка
**User:** «Мне плохо, не вижу выхода»  
**Bot:** 
- Распознаёт кризисные маркеры
- Предлагает техники заземления
- Даёт контакты экстренных служб
- Эскалирует к живому специалисту при необходимости

**Success:** Пользователь стабилизирован, получил поддержку, знает куда обратиться

---

### UC2: Тревога и страхи
**User:** «Постоянно тревожусь, не могу расслабиться»  
**Bot:**
- Валидация чувств (ННО)
- Техники дыхания и заземления
- Когнитивная работа с мыслями
- Парадоксальная интенция (Франкл)

**Success:** Пользователь освоил 2-3 техники, чувствует облегчение

---

### UC3: Поиск смысла
**User:** «Всё есть, но чувствую пустоту. Зачем всё это?»  
**Bot:**
- Логотерапия (Франкл): 3 пути к смыслу
- Интегральная карта (Уилбер): где застревание
- Вопросы для самоисследования

**Success:** Пользователь определил 1-2 направления для поиска смысла

---

### UC4: Конфликты и отношения
**User:** «Постоянно ссорюсь с партнёром/коллегами»  
**Bot:**
- ННО: 4 компонента для диалога
- Юнг: проекции и Тень
- Литвак: амортизация в конфликтах

**Success:** Пользователь попробовал технику, конфликт снизился

---

### UC5: Самопознание
**User:** «Хочу понять себя лучше, свои паттерны»  
**Bot:**
- MBTI: тип личности, когнитивные функции
- Юнг: архетипы, индивидуация
- Дневник самопознания

**Success:** Пользователь прошёл тест, получил инсайты

## 🚫 Non-Goals

### Что ПиФ НЕ делает:

| Non-Goal | Почему |
|----------|--------|
| **Замена терапии** | Не диагностирует, не лечит расстройства |
| **Медицинские советы** | Не заменяет психиатра, не назначает лекарства |
| **Кризисное вмешательство** | Не заменяет скорую помощь, только эскалация |
| **Хранение личных данных** | Приватность優先, минимальные логи |
| **Монетизация через ads** | Никакой рекламы в диалогах |

## ✅ Acceptance Criteria

### Для кризисного распознавания:

- [ ] Распознаёт суицидальные маркеры с точностью >95%
- [ ] Предлагает контакты служб в течение 5 секунд
- [ ] Эскалирует к оператору при повторных кризисах
- [ ] Логирует инциденты для супервизии

### Для ННО-диалога:

- [ ] Каждый ответ содержит 4 компонента (явно или имплицитно)
- [ ] Избегает советов в формате «вам следует...»
- [ ] Валидирует чувства пользователя
- [ ] Задаёт открытые вопросы

### Для безопасности:

- [ ] Никаких персональных данных в логах
- [ ] Шифрование данных в rest и transit
- [ ] Соответствие 152-ФЗ и GDPR
- [ ] Пользовательское согласие на обработку

## 🛠️ Technical Architecture

### Stack:

- **LLM:** OpenRouter (qwen3.5-plus-02-15, sonar-pro)

- **Backend:** Node.js, OpenClaw framework
- **Database:** SQLite (локально), vector DB для RAG

## 🔒 Ethics & Safety

### Guidelines:

1. **Прозрачность:** Чёткий дисклеймер, что это AI, не терапевт
2. **Эскалация:** Кризисы → живые специалисты
3. **Приватность:** Минимальные данные, шифрование
4. **Супервизия:** Аудит диалогов психологами
5. **Ограничения:** Не диагностирует, не лечит, не заменяет терапию

### Red Lines:

- ❌ Никаких медицинских диагнозов
- ❌ Никаких советов по лекарствам
- ❌ Никакой рекламы в диалогах
- ❌ Никакой передачи данных третьим лицам
